### [OOS] 缺货 / 超卖
- **触发**：在手库存 < 本批应发数量　｜　**首响**：2 小时内
- **动作**：
  1. 立即停发该 SKU，不再接新单（先把链接改为「无货」或下架，别继续卖）
  2. 查上家 / 补货在途，能给出确切到货日就等，给不出就不要等
  3. 按「先补偿后解释」处理：主动告知 + 给方案，不等买家发现
  4. 同一 SKU 连续两次超卖，把警戒线上调一档
- **可发话术**（≤60 字，`【】` 填实）：`实在抱歉，这款刚被前一位拍走了，我这边补货要【N】天。给您两个选择：等货我补偿【X】元，或现在全额退款我立刻处理。`
- **责任**：仓捷运 → 同步 customer-service、ops-director

### [WRONG] 错发 / 漏发配件
- **触发**：买家反馈型号不符或配件缺失，或发货前核对发现　｜　**首响**：1 小时内响应
- **动作**：
  1. 先要开箱视频 / 照片，确认是错发还是买家误判
  2. 确属错发：不要求寄回再发，直接补发正确的，旧的让买家留着或到付退回
  3. 漏配件：当天补寄，运费你出，别让买家垫
  4. 记录到「错发台账」，同一环节连续出错就改流程（多数是拣货没读全型号）
- **可发话术**（≤60 字，`【】` 填实）：`是我这边发错了，不折腾您寄回。正确的那件我今天就补发，单号出来第一时间发您，运费我承担。`
- **责任**：仓捷运

### [DMG] 运输破损
- **触发**：买家开箱发现破损 / 功能异常　｜　**首响**：2 小时内响应
- **动作**：
  1. 第一句先要证据：开箱视频（未剪辑）+ 外箱六面照 + 破损特写
  2. 有保价先走保价理赔，同时先给买家方案（换 / 退 / 部分退款），别让买家等理赔
  3. 责任在包装就改包装（加护角、双层箱），责任在承运就换承运
  4. 全程站内沟通，不要转微信——平台只认站内记录
- **可发话术**（≤60 字，`【】` 填实）：`看到破损了，真不好意思。麻烦您拍一下外箱六面和开箱视频，我这边同时走理赔，先给您安排换新/退款，不让您等。`
- **责任**：仓捷运 → customer-service

### [STALE] 物流滞留 / 无更新
- **触发**：单号超过 72 小时无轨迹更新　｜　**首响**：当天处理
- **动作**：
  1. 先自己查：打承运客服要「异常件」处理单号，不要只让买家等
  2. 能催则催，48 小时仍无进展直接补发或退款，再向承运索赔
  3. 主动告知买家当前进展与预计时间，每 24 小时同步一次
  4. 同一承运连续滞留 2 单，换承运商
- **可发话术**（≤60 字，`【】` 填实）：`您的件在【XX】中转卡住了，我已经报了异常件在处理，最迟【N】天有结果。真送不到我直接给您补发/退款，不让您干等。`
- **责任**：仓捷运

### [REJECT] 拒收 / 退货
- **触发**：买家拒收或申请退货退款　｜　**首响**：4 小时内响应
- **动作**：
  1. 先问原因：不想要了 / 与描述不符 / 破损，三类处理完全不同
  2. 七天无理由范围内、商品完好：痛快退，别拖，拖延只会升级成纠纷
  3. 主张「与描述不符」：回到详情页与留证视频，能对上就协商部分退款，对不上就认
  4. 退回件当场验货再签收，破损拒签并录像
- **可发话术**（≤60 字，`【】` 填实）：`可以的，您申请退货退款我这边就通过。麻烦按原包装寄回，收到验完当天给您退款，运费按平台规则来。`
- **责任**：仓捷运 → customer-service

### [ADDR] 地址不详 / 电话不通
- **触发**：面单信息缺省市区、电话空号、地址为驿站代号　｜　**首响**：发货前解决，不猜
- **动作**：
  1. 一律站内问清完整地址，不要按记忆或历史地址填
  2. 买家 12 小时不回复就先不发货，超 48 小时按缺货口径沟通
  3. 寄出后被退回：运费按责任分，买家填错则买家承担（提前在详情页写明）
  4. 面单打印后逐字复核收件人姓名/电话/地址三项
- **可发话术**（≤60 字，`【】` 填实）：`您这个地址少了【区/街道】，快递发不出去。麻烦补一下完整地址和电话，我这边确认后马上发。`
- **责任**：仓捷运 → customer-service

### [DAODAO] 到手刀（发货前预防）
- **触发**：买家收货后以瑕疵为由要求大额补偿　｜　**首响**：转 customer-service，按议价阶梯处理
- **动作**：
  1. 发货前把瑕疵拍进详情页与聊天记录，这是最有效的预防
  2. 留证视频一镜到底，序列号必须入镜
  3. 买家提出补偿：先要证据，再按 service_reply 的让步阶梯处理，不接受威胁式索赔
  4. 遇到威胁差评 / 曝光：不私了、不转账，全部走平台流程
- **可发话术**（≤60 字，`【】` 填实）：`瑕疵在详情页第【N】张图有标注，发货视频里也能看到。您先拍一下实物，我核实后按实际情况处理。`
- **责任**：customer-service 主责，仓捷运提供留证

### [DROPSHIP] 代发上家延迟 / 发错
- **触发**：无货源代发，上家超过 24 小时未出单号　｜　**首响**：当天处理
- **动作**：
  1. 下单前先确认上家库存与发货时效，别拿「有货」当默认
  2. 上家超 24 小时未发：立刻催，同时准备备选上家
  3. 上家发错 / 发劣：不让买家承担，你直接兜底补发或退款，再与上家结算
  4. 同一上家一个月出 2 次问题，换掉
- **可发话术**（≤60 字，`【】` 填实）：`仓库那边排单慢了点，我已经催了，最迟【N】天出单号。要是再拖我直接给您退款，不让您等着。`
- **责任**：仓捷运 → ops-director

## 七、「48 小时发货」怎么写才不翻车

1. 无货源 / 代发：只写「48 小时内发出」，不写「现货」「当天发」——你没有货，仓在上家。
2. 有现货：可写「现货，付款后 48 小时内发出」，仍不写「当天发」除非你确实每天截单前发。
3. 时效是「发出」不是「到达」：48 小时承诺的是交寄时间，运输天数由承运方决定，别替快递打包票。
4. 写清不可抗力例外：节假日、疫情管控、极端天气导致延迟，提前在详情页与私聊说清。
5. 超时了主动说：先补一句说明 + 给补偿方案（小额红包 / 包邮 / 赠品），比等买家来问强十倍。
