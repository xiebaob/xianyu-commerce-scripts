## 1. 二手 Switch OLED 掌机

> 品类判定：**游戏机掌机**　｜　信号来源：GH
> 选品归类：掌机

### 定价与锚点
- 同款价格带：¥1,450 ~ ¥1,850，中位 **¥1,650**
- 建议挂牌价：中位 **-3% ~ +5%**，即 ¥1,600 ~ ¥1,732
- 前 3 天冲量价：中位 **-5% ~ -8%**，即 ¥1,568 ~ ¥1,518
- 本单毛利：**¥399**（毛利率 22.2%）
- 利润门槛（≥30 元 或 ≥20%）：✅ 达标

### 主图文案
- **首图大字**（≤16 字，手机缩略图也看得清）：`95新 Switch OLED`
- **副标**（一行，说事实不说形容词）：`港版/含底座/无拆修`
- **价格锚点**：`【现价 ¥1799（对比同款中位 ¥1899）】`
- **角标**：`支持验货宝 / 可验机`
- 版式：主体居中偏左，文字压右侧 1/3，底部留 8% 安全边距（防平台裁切）

### 拍摄清单（游戏机掌机，共 9 张）
1. **白底主图** — 1:1，主体占画面 65%~75%，纯白或浅灰背景，无杂物
   - 目的：决定点击率，只放一个主卖点 + 价格锚点；💡 手机横放拍、开闪光灯易反光，用两张 A4 纸做反光板
2. **正面全景** — 自然光，45° 或正上方俯拍，完整入镜不留切边
   - 目的：让人一眼看清是什么、大概什么成色；💡 靠窗拍，别用顶灯直射，阴影会吃掉细节
3. **关键细节特写** — 近距离对焦，突出材质 / 接口 / 按键 / logo
   - 目的：证明是真机实拍，降低「网图」疑虑；💡 用手指做参照物，顺便体现尺寸
4. **瑕疵 / 使用痕迹特写** — 把最明显的瑕疵拍清楚，不要回避
   - 目的：主动披露可大幅降低到手刀和退货率；💡 文案同步写「正常使用痕迹，介者慎拍」
5. **配件全家福 + 尺寸参照** — 所有随附配件平铺，旁边放尺子或常见物（如银行卡）
   - 目的：减少「少发了配件」类纠纷；💡 缺什么就写清楚缺什么，别用「如图」含糊
6. **开机进入系统主界面（版本号 / 序列号打码）**（品类必备）
7. **手柄按键回弹与摇杆漂移测试**（品类必备）
8. **屏幕坏点与划痕特写**（品类必备）
9. **电池续航与是否拆修说明**（品类必备）

### 详情页结构（4 屏）
**第 1 屏 · 首屏：一句话卖点 + 价格锚点**
- 一句核心卖点（≤15 字，说人话不说形容词）
- 原价 / 现价对比锚点
- 三个核心参数，一行一个
**第 2 屏 · 信任背书**
- 可验机 / 验货宝标识
- 购买凭证、发票或保修状态截图（打码）
- 实拍承诺：本页所有图为本人实拍
**第 3 屏 · 参数与成色**
- 型号 / 配置 / 版本
- 成色分级与瑕疵明示（位置 + 程度）
- 配件清单：有就是有，没有就是没有
**第 4 屏 · 售后与物流**
- 发货时效（无货源代发写明 48 小时）
- 退换规则与运费承担方
- 包装方式（防摔 / 防压说明）

**本品类必须写清（缺一条就等着退货）：**
- [ ] 是否国行 / 港版 / 日版
- [ ] 是否被 BAN、能否正常联网
- [ ] 屏幕有无坏点、划痕位置
- [ ] 账号是否已解绑

| 1 | 0-3s | 手持实物入镜 + 一句话钩子 | 钩子说价格或稀缺性，不要自我介绍 |
| 2 | 3-8s | 外观 360° 缓慢转一圈 | 稳定压倒一切，别晃 |
| 3 | 8-15s | 核心功能实际操作演示 | 口播同步说「这台能干什么」 |

- 拼装骨架：`95新 二手 Switch OLED 掌机 【型号/容量/版本】 支持验机 急出`
- 信号词参考：
  - 回血词：急出、回血、闲置、搬家清仓
  - 成色词：9成新、95新、99新、全新未拆
  - 信任词：支持验机、验货宝、可当面验、实拍
  - 应季词：冬季、开学季、毕业季、换季
- 核心搜索词（来自选品）：`Switch OLED 港版`

### 违规自查
- ✅ 未命中硬违规词 / 需核对词
- 本品类高风险点：机器被 BAN 无法联网；屏幕坏点隐瞒；电池鼓包 / 续航虚标；账号未解绑导致锁机

### 点击率优化要点
1. 首图只有一个卖点，别把 5 个卖点全塞进主图
2. 价格锚点必须是具体数字，不写「低价」「超值」
3. 主图文字 ≤ 12 字，手机端缩略图也能看清
4. 瑕疵图必须放，主动披露比藏着更能促成下单
5. 同一 SKU 至少准备 2 版主图做 A/B，48 小时后看点击率
6. 所有图统一水印 / 统一色调，形成店铺识别度
