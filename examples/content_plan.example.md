## 四、逐篇脚本要点

### 通用骨架（两种形式，先记住再写单篇）

**图文**
- 第 1 段（3 行内）：身份 + 价格 + 一句反常识结论。别写「大家好」
- 第 2 段：核心信息 3 条，每条一句结论 + 一句依据
- 第 3 段：瑕疵主动交代（位置 + 程度 + 影响）
- 第 4 段：适合谁 / 不适合谁
- 结尾：站内钩子（想要的直接拍 / 检查表私信要），不留任何站外联系方式

**视频**
- 0-3s 钩子：手持实物 + 反常识结论，不自我介绍
- 3-8s 外观 360°：稳定压倒一切，不要运镜炫技
- 8-18s 真实使用：一个具体场景，说人话
- 18-25s 瑕疵特写：主动说，转化反而更高
- 25-30s 结论 + 站内行动号召
